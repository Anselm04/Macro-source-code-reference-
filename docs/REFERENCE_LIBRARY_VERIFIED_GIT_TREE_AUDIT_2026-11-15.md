# Full TrillionAI Source Reference Library — Verified Pinned Git-Tree Audit

**Audit date:** 15 November 2026 (NZ)  
**Scope:** 31 public Anselm04 source-code-reference repositories, the source of every original Git-tracked file at each repository's documented pinned upstream revision, and the current main branch.  
**Verification method:** Fetch upstream Git commit and tree (without executing source); recursively enumerate entries via `git ls-tree -rz`; compare each path, Git object SHA and mode to the destination `main` tree; publish a full per-path JSON delta. Original CI workflow files are additionally archived under inert non-`.github/workflows` paths and their Git blob SHA checked before committing. Where previously omitted source files were repaired, rerun the full pinned upstream comparison.

## Limits of this verification and engineering practices

1. These are exact **pinned Git-tracked source comparisons**, not full upstream commit histories. There is no assertion that private vendor services, deployment keys, proprietary unavailable code, or downloaded dependency packages are available.
2. Gitlinks record submodule commit identity; **they do not contain the external submodule's checked-out source files**. LFS pointers likewise do not establish that LFS payloads were downloaded.
3. Upstream CI workflows were preserved as **non-executable inert source snapshots**. Never activate them without a separate security review.
4. Sensitive credential material remains excluded from public TrillionAI copies to avoid exposing secrets; research its format through safe redacted examples and upstream documentation.
5. Separately licensed source may be studied via official upstream links where access is permitted, but public visibility does **not** grant unconditional rights to republish or embed it in commercial proprietary apps. Implement new TrillionAI products independently, preserve provenance, and assess specific licence and patent obligations before reuse.
6. Original source import was not a build, dependency installation, functional test, security audit, or demonstration of a working third-party deployment.
